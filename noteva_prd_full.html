Design Principles
Brutalist Aesthetic
Sharp 2px borders. No blurry shadows. Zero or tight (4px) corner radii. Monochromatic base with surgical use of #FF5252. Every element is intentional — no decoration for decoration's sake.
Local-First
All data stored on-device via SQLite. No cloud dependency for core features. Works 100% offline. User owns their data. JSON export/import for portability.
Gesture-Driven
Long-press reveals quick actions. Swipe-to-delete. Pinch-to-zoom on images. Secret long-press on FAB opens Vault PIN entry. Haptic feedback on every critical action.
60fps Performance
FlashList (Shopify) for all heavy lists. Reanimated 3 on the UI thread — zero JS bridge lag. Skeleton loaders for perceived speed. Memo + callback everywhere.

MVP

Folder System

MVP
🔒
Private Vault
Secret long-press on FAB (800ms) triggers PIN modal. Notes marked isLocked hidden from main list. PIN stored in expo-secure-store. Biometric unlock optional.
MVP
🖼️
Image System
Multiple images per note. Pinch-to-zoom resize in editor. Drag-handle repositioning. Full-screen preview with shared element transition. Stored in local FS.
MVP
⏰
Reminders
Set "Notification" or "Alarm"-style reminders per note. expo-notifications integration. Supports one-time and repeating triggers. Displayed in note card.

Global full-text search across all notes. Tag-based filtering. Tags stored as JSON array in DB. Search indexed on title + content. Live results as user types.
MVP

Export all notes, folders, settings as JSON to local file system or share sheet. Import from JSON to restore. Version-tagged backup files. One-tap flow.

05
Technical Stack
Framework
React Native + Expo SDK 51+
Cross-platform iOS/Android. Expo managed workflow for fast iteration. EAS Build for distribution.
Navigation
Expo Router v3
File-based routing. Deep linking out of the box. Typed routes. Stack + Modal navigators.
Database
Expo SQLite (expo-sqlite)
Local-first persistence. Synchronous reads for lists. Async writes. Indexed queries for search.
State
Zustand
Minimal boilerplate. No provider needed. Slices: noteStore, folderStore, settingsStore, vaultStore.
Animations
Reanimated 3 + Moti
UI thread animations = no JS bridge jank. Moti for declarative transitions. Gesture Handler for swipe/pinch.
Lists
FlashList (Shopify)
10x faster than FlatList for large note lists. Recycled views. Stable 60fps on mid-range devices.
Rich Text
react-native-pell-rich-editor
WebView-based, proven stable. Supports Bold, Italic, Lists, Blockquote, Checklist. Custom toolbar.
Icons
Lucide React Native
Consistent 24px stroke icons. Tree-shakeable. Used for all UI chrome, toolbar buttons, settings.
Haptics
expo-haptics
Native haptic engine on iOS + Android. Impact, Notification, Selection feedback types.
Notifications
expo-notifications
Local notifications + alarms. Works on both platforms. Permission request at first reminder set.
Security
expo-secure-store
Keychain (iOS) / Keystore (Android) for PIN hash storage. Never stored in SQLite plain-text.
Images
expo-image-picker + expo-file-system
Camera & gallery access. Images copied to app's document directory for persistence across sessions.

State Architecture (Zustand)

noteStore
notes[], selectedNote, isLoading, searchQuery, filterFolderId, viewMode (grid/list). Actions: loadNotes, createNote, updateNote, deleteNote, togglePin, toggleLock.
folderStore
folders[], activeFolderId. Actions: createFolder, updateFolder, deleteFolder, reorderFolders.
vaultStore
isUnlocked, pinHash. Actions: unlockVault, lockVault, setPin, verifyPin. PIN stored in expo-secure-store as SHA-256 hash.
settingsStore
theme, fontSize, gridMode, hapticEnabled. Persisted to SQLite settings table on every change.

AI Master Prompt (Copy & Use)

নিচের প্রম্পটটি কপি করে যেকোনো AI (Claude, ChatGPT, Gemini) তে দিলে সরাসরি কোড পাবেন:

MASTER PROMPT
You are building "Noteva", a production-ready React Native Expo app.

AESTHETIC: High-contrast Brutalist. #FF5252 accent. Pure black bg. Space Mono for metadata, Syne for headings. Sharp 2px borders, no soft shadows, rx=4 max.

STACK: Expo SDK 51 + Expo Router v3 (file-based nav) + Expo SQLite (local DB) + Zustand (state) + Reanimated 3 + FlashList + lucide-react-native + expo-haptics + expo-notifications + expo-secure-store.

DB SCHEMA: notes(id UUID PK, title TEXT, content TEXT, images_json TEXT, tags_json TEXT, color TEXT, is_locked INT, is_pinned INT, reminder_at INT, reminder_type TEXT, folder_id FK, created_at INT, updated_at INT). folders(id, name, icon, color, sort_order, created_at). settings(key PK, value).

FEATURES:
1. Home: FlashList notes in 2-col bento grid + list toggle. Horizontal folder bar. Long-press card = bottom sheet (Pin/Delete/Lock/Move). FAB (+). Long-press FAB (800ms) = PIN modal for Vault.
2. Editor: react-native-pell-rich-editor. Bold/Italic/List/Quote toolbar. Multi-image support with pinch-to-zoom. Auto-save 5s + blur. "Done" button → SQLite write → impactAsync(Medium).
3. Vault: isLocked notes hidden from main list. PIN entry modal (4-digit). PIN stored as SHA-256 in expo-secure-store. notificationAsync(Error) on wrong PIN.
4. Reminders: expo-notifications local triggers. 'notification' or 'alarm' type per note. Permission request on first use.
5. Settings: Light/Dark theme. Font size (S/M/L). JSON backup/restore. PIN setup/change.
6. Haptics: ALL save/delete/lock/pin actions have expo-haptics feedback. See haptics spec.

START WITH: Step 1 — SQLite schema file (database/schema.ts). Step 2 — Zustand stores. Step 3 — Home screen UI with folder bar + FlashList note grid in Brutalist style.
